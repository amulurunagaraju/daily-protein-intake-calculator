Daily Protein Intake Calculator

About the Project:

A Python program that estimates daily protein intake from eggs, soya chunks and green gram/chana based on the quantities entered by the user.

Features:

- Accepts the number of eggs consumed.
- Takes the quantity of soya chunks in grams.
- Takes the quantity of green gram/chana in grams.
- Calculates protein from each food source.
- Displays total estimated protein intake.
- Provides feedback based on the calculated amount.

Technologies Used

- Python

How to Run:

1. Download the "protein_intake_calculator.py" file.
2. Run it using Python.
3. Enter the quantities of the listed food items.
4. View the estimated total protein intake.
